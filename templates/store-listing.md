# Ficha de tienda (llénala una vez, úsala en ambas)

Lo mínimo para que la ficha no bloquee el envío: nombre, descripción corta, descripción larga en borrador, ícono, feature graphic (Android), 2 o 3 capturas reales y la URL de privacidad. El texto promocional se puede editar con la prueba ya publicada.

![Tamaños que desbloquean la ficha](../web/img/assets.svg)

| Campo | Valor | Límite |
|---|---|---|
| Nombre de la app | | 30 |
| Subtítulo (iOS) / Descripción corta (Android) | | 30 / 80 |
| Descripción larga | | 4000 |
| Palabras clave (iOS) | | 100 (separadas por coma) |
| Categoría | | |
| Email de soporte | | |
| URL de soporte | | |
| URL de política de privacidad | | |
| URL de marketing (opcional) | | |
| Novedades de la versión | | 4000 |
| Cuenta demo para revisión (usuario / clave) | | |
| Notas para el revisor | | |

## Assets
- [ ] Ícono 1024×1024 (iOS, sin transparencia) y 512×512 (Android)
- [ ] Feature graphic 1024×500 (Android)
- [ ] Capturas Android (mínimo 2)
- [ ] Capturas iPhone 6.9" (y iPad si aplica)
- [ ] Video preview (opcional)
